`bba.quote_grounder.verify_citation` checks a model citation against the redacted evidence. It rejects an empty quote first, then evaluates the mandatory checks until one fails. A passing citation must satisfy every applicable check.

<QuoteGroundingLayers />

## Verification result

The verifier returns the first failure reason. Missing or duplicated source IDs fail as `CITED_ID_NOT_FOUND`. Quote comparison uses NFC-normalized text and word-aligned substring boundaries. Uniqueness uses the same boundaries.

Numeric grounding compares supported analyte, value, and unit triples. Any structured `lab_tuple` must match a triple parsed from the quote itself. This is narrower than checking every number or proving that a clinical conclusion is correct.

The pipeline verifies attempts against the row's redacted evidence and selects the latest passing attempt. If no attempt passes, it writes `final_classification = NEEDS_REVIEW` with `review_reason = "hallucination_suspect"`. That reason is a flag, not a classification literal. See [Audit store](/blood_audit/en/developers/audit-store/).

Recovery uses the same real verifier. A cached response does not bypass grounding, and a changed request cannot reuse an older response merely because the audit ID matches.

## Optional NLI check

`verify_citation(..., nli_gate=None)` omits the NLI check. A caller can supply an `NLIEntailmentGate` for an additional entailment predicate. The default application does not supply one.

The gate receives the normalized cited source as its premise and the normalized quote as its hypothesis. This interface does not by itself verify every statement in a reasoning summary. Text grounding establishes where a quote came from. Clinical validation and reviewer judgment remain separate requirements.

## Test the boundary

Exercise the actual verifier with synthetic adversarial fixtures. Cover missing IDs, duplicate source IDs, short quotes, shifted word boundaries, repeated text, and conflicting lab tuples. Keep the production minimum at `MIN_QUOTE_LENGTH = 25`. The API's `min_length` parameter supports evaluation sweeps and does not justify weakening application grounding.

The ordered checks live in `src/bba/quote_grounder/verifier.py`. Individual predicates live in `src/bba/quote_grounder/layers.py`.
