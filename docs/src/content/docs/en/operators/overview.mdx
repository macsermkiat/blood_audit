Run `bba audit` to turn a HOSxP export into committed classifications for retrospective quality improvement. Start with [Install](/blood_audit/en/operators/install/) and [First audit run](/blood_audit/en/operators/first-audit-run/).

The local mode needs Python, uv, a complete export, and private persistent storage. It commits deterministic results without a model API key or Postgres. Cases that need model evidence remain `NEEDS_REVIEW` with `privacy_admission_failed`.

## Prepare the export and storage

Stage the 13 canonical CSVs together. The exporter must apply the approved adult cohort filter because the bundle has no age column. See the [input table reference](/blood_audit/en/operators/ingest-csv/#expected-tables).

Use a service account and access-controlled persistent storage for `BBA_DATA_DIR`. Back up its `identity.key` with the audit records. The key keeps patient and admission pseudonyms stable. Treat source snapshots, reports, and logs as clinical records under the approved retention policy.

## Add model review when approved

Cassette and live model modes require an application configuration, a privacy trust policy, signed evidence artifacts, and a migrated Postgres checkpoint store. Live mode also requires the optional provider dependency, an API key, and explicit `allow_live_api` approval in configuration.

A separate approved local redaction service owns the model and private signing key. The audit application receives the public verification key and signed evidence. The CLI does not install a redactor or configure hospital identity services. See [Deployment integrations](/blood_audit/en/operators/integration-seams/).

The application supports retrospective review. It does not notify treating clinicians or establish clinical validity by running successfully.

## Platelet route limit

`PLATELET_LLM_ENABLED` is false in the repository configuration. If a bundle contains platelet orders that require the disabled review route, the application rejects the uncommitted work and does not mark the run complete. A local audit is not a guarantee that every platelet order can complete. Confirm the approved deployment route before selecting a platelet cohort.
