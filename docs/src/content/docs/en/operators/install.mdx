title: Install
description: Install the source checkout and verify the available CLI commands.
---

Install Python 3.13 or later and uv. Use the lockfile to install the repository dependencies.

```sh
git clone https://github.com/macsermkiat/blood_audit.git
cd blood_audit
uv sync --frozen
uv run bba --help
```

The help output lists six commands: `audit`, `evaluate`, `ingest`, `report`, `sentinel`, and `serve-dashboard`. Use each command's `--help` for its arguments.

The local audit mode needs no Postgres connection or provider key. Continue to [First audit run](/blood_audit/en/operators/first-audit-run/).

## Install the live provider dependency

For an approved live model deployment, sync the optional dependency group.

```sh
uv sync --frozen --extra live
```

Run live commands with `uv run --extra live bba ...` so uv retains that dependency. Complete the [model configuration](/blood_audit/en/operators/env-vars/#model-review) before running hospital data.

## Prepare a database deployment

Use the source checkout when deploying model checkpoints or the reviewer service. The root Alembic migration project is an operational dependency and is not bundled in the standalone wheel. Apply the matching migrations and configure the required database roles before starting the service.

The dashboard checks the review role's migration state and privileges. It requires an unprivileged reviewer role, an HTTPS reverse proxy, and an identity adapter that issues signed sessions. See [Deployment integrations](/blood_audit/en/operators/integration-seams/#serve-authenticated-review).

Docker is needed for the container-backed Postgres tests, rather than for a local audit. The [testing guide](/blood_audit/en/developers/testing/) describes required database checks.
