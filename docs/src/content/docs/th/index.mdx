## จากข้อมูลส่งออกสู่การทบทวน

ระบบอ่านชุดข้อมูลจาก HOSxP ที่ส่งออกหลังการดูแล และตรวจสอบคำสั่งให้เลือดแดงเข้มข้น
กับเกล็ดเลือดตามกฎที่กำหนดไว้ในโค้ด ผลแต่ละรายการเก็บหลักฐานและข้อมูลรุ่นของกฎ
หรือโมเดลที่ใช้ไว้ด้วย

1. เตรียมชุด CSV ตามรูปแบบที่กำหนด แล้วใช้คำสั่ง `bba audit`
2. เปิดผลที่บันทึกแล้วและรายการที่ยังต้องทบทวนในแดชบอร์ดที่ตรวจสอบตัวตนผู้ใช้
3. สร้างรายงานสำหรับคณะกรรมการ หรือเปรียบเทียบผลระหว่างรอบการตรวจสอบ

โหมดเริ่มต้นประมวลผลในเครื่องโดยไม่เรียกโมเดลภายนอก รายการเลือดแดงที่ยังสรุปไม่ได้
จะบันทึกให้ทบทวนด้านความเป็นส่วนตัว การเรียกโมเดลต้องมีหลักฐานที่ลงนามโดยบริการ
ลบข้อมูลระบุตัวตนที่ได้รับอนุมัติ และฐานข้อมูลสำหรับติดตามการประมวลผล
เส้นทางเรียกโมเดลของเกล็ดเลือดปิดไว้โดยค่าเริ่มต้น รายการที่ยังไม่ได้บันทึกผลอาจทำให้
รอบการตรวจสอบไม่สำเร็จ ดูเงื่อนไขใน[คู่มือเริ่มต้น](/blood_audit/th/operators/first-audit-run/)

รายการคืนเลือด เจตนาการใช้เลือด และการจองก่อนผ่าตัดอาจได้รับการจัดเส้นทางก่อนตรวจค่า Hb
หรือเกล็ดเลือด ผลที่ยกเว้นจากการคิดคะแนน การจองเกิน และหลักฐานไม่เพียงพอมีความหมายต่างกัน
อ่าน[สรุปกฎ](/blood_audit/th/clinical/policy-summary/) ก่อนตีความรายงาน

## ขอบเขตการใช้งาน

ระบบนี้ใช้ตรวจสอบย้อนหลังเพื่อพัฒนาคุณภาพในผู้ป่วยในผู้ใหญ่ของโรงพยาบาลจุฬาลงกรณ์
ไม่ใช้อนุมัติคำสั่งให้เลือด ณ จุดดูแล การทดสอบซอฟต์แวร์ยืนยันพฤติกรรมตามโค้ด
ส่วนความถูกต้องทางคลินิก คุณภาพการลบข้อมูลระบุตัวตน และการควบคุมระบบที่ติดตั้งจริง
ต้องมีหลักฐานการประเมินแยกกัน
