หน้านี้อธิบายกฎที่โค้ดใน repository ใช้อยู่ โดยสรุปจากนโยบายภายใน KCMH รวม PR 17.2 และข้อกำหนด Hb สามระดับ ไม่ใช่แนวทางสั่งเลือด ณ จุดดูแล หากโค้ดขัดกับนโยบายที่สถาบันอนุมัติ ต้องให้ทีมคลินิกตรวจสอบก่อนนำไปใช้

## เกณฑ์ RBC

<HbTierMatrix />

ค่า Hb ที่เท่ากับเกณฑ์ถือว่าผ่านเกณฑ์ตัวเลขด้วย หน่วยเป็น g/dL

| Cohort | เกณฑ์ Hb | บริบท |
| --- | --- | --- |
| `default` | 7.0 | ไม่เข้า cohort ที่มีเกณฑ์สูงกว่า |
| `esrd_epo` | 7.0 | ภาวะซีดจากไตที่ใช้ EPO เพียงอย่างเดียวไม่เพิ่มเกณฑ์ |
| `cardiac_surgery` | 7.5 | หัตถการหัวใจที่เข้าเงื่อนไข |
| `ortho_surgery` | 8.0 | การผ่าตัดกระดูกที่เข้าเงื่อนไข ไม่ต้องมีประวัติโรคหัวใจร่วม |
| `cardiopulmonary_comorbidity` | 8.0 | การวินิจฉัยโรคหัวใจที่เข้าเงื่อนไข ชื่อเดิมยังอยู่ แต่โรคปอดเพียงอย่างเดียวไม่เข้าเกณฑ์นี้ |

`ortho_cardiac` เก็บไว้รองรับข้อมูลเก่า ส่วนตัวตรวจปัจจุบันใช้ `ortho_surgery` สำหรับกฎผ่าตัดกระดูก `mtp`, `heme_malignancy_active` และ `cohort_unknown` ไม่มีเกณฑ์ตัวเลข ระบบจึงต้องพิจารณา label ร่วมด้วย

## การยกเว้นและการจองเลือด

ก่อนพิจารณา Hb ระบบสามารถให้ผลดังต่อไปนี้ตามการตั้งค่าเริ่มต้น

- `RETURNED_NOT_TRANSFUSED` เมื่อทุกยูนิตคืนโดยไม่ได้ให้เลือด
- `PERIOP_TRANSFUSION_EXEMPT` เมื่อประกาศใช้เพื่อผ่าตัดหรือ type-and-screen จาก `BDVSTDT.USETYPE` รหัส `2` หรือ `3`

ทั้งสองผลไม่รวมในคะแนนความเหมาะสม การยกเว้นไม่ได้ยืนยันว่ามีข้อบ่งชี้ให้เลือด

การตรวจการจองเลือดแบบ MSBOS เปรียบเทียบจำนวนที่จองกับเกณฑ์ของการผ่าตัดที่วางแผนไว้ การจองเกินอาจได้ `PREOP_OVER_RESERVATION` หากหัตถการไม่ชัดหรือข้อมูลขาด ระบบส่งให้ทบทวน เกณฑ์เกล็ดเลือดสำหรับการจองก่อนผ่าตัดเป็นกฎแยกจากข้อบ่งชี้การให้เกล็ดเลือดด้านล่าง แถวที่ยกเว้นอาจมี `reservation_annotation` โดยผลจำแนกเดิมไม่เปลี่ยน

## ลำดับการตัดสิน RBC

<AlgorithmDecisionFlow />

แผนภาพเริ่มหลังการตรวจระดับคำสั่งและแสดงเส้นทางเริ่มต้นเมื่อมี Hb หากไม่มี Hb โดยปกติได้ `INSUFFICIENT_EVIDENCE` มีโหมดทางเลือกที่ใช้หลักฐานซึ่งไม่ต้องอาศัย Hb หรือส่งให้ LLM แต่โหมดนี้ไม่ได้เปิดโดยค่าเริ่มต้น

กฎ `Hb ≤ 7.0` มาก่อน MTP และ cohort ที่ไม่ทราบบริบท จากนั้น MTP จึงให้ `APPROPRIATE` สำหรับคำสั่งที่เหลือ ส่วน `cohort_unknown` เมื่อ `Hb > 7.0` จะส่งทบทวนก่อนตรวจ bypass อื่น

Delta-Hb ต้องลดอย่างน้อย 1.5 g/dL ใน 6 ชั่วโมง, 2.0 ใน 12 ชั่วโมง หรือ 2.5 ใน 24 ชั่วโมง สำหรับ cohort ที่มีเกณฑ์สูงกว่า 7.0 การได้ crystalloid อย่างน้อย 2 L ใน 4 ชั่วโมงก่อนสั่ง หรือ Hb ต่ำครั้งเดียวโดยไม่มีแนวโน้มก่อนหน้า อาจทำให้ผลที่ควรผ่านเกณฑ์ตัวเลขต้องส่งทบทวน การตรวจเหล่านี้ไม่ย้อนเปลี่ยนผลจากกฎ `Hb ≤ 7.0` และ vital signs เพียงอย่างเดียวไม่ทำให้เกิด deterministic bypass

หากปิดการยกเว้นจาก declared-use เส้นทางเก่าอาจให้ผ่านเมื่อมีหัตถการใน 6 ชั่วโมงก่อนสั่ง ส่วนหัตถการที่จะเกิดใน 72 ชั่วโมงหรือการประกาศใช้เพื่อผ่าตัด จะส่งคำสั่งที่ Hb สูงกว่าเกณฑ์ให้ LLM ทบทวน ไม่ใช่อนุมัติโดยอัตโนมัติ

## ค่า Hb และกลุ่มผู้ป่วย

ตัวจำแนก deterministic ใช้ Hb ก่อนเวลาสั่งที่เลือกจากการค้นย้อนหลังเจ็ดวัน พร้อมข้อมูลแหล่งที่มาและอายุผล ส่วนหลักฐาน `SUB_THRESHOLD_HB` ในเส้นทาง LLM ใช้ Hb ต่ำสุดใน 24 ชั่วโมงก่อนสั่ง โดยไม่นับค่าก่อนการให้เลือดครั้งล่าสุดในช่วงนั้น ทั้งสองค่าใช้คนละหน้าที่

ระบบมีขอบเขตสำหรับผู้ป่วยในผู้ใหญ่ ผู้ติดตั้งต้องจัดเตรียมชุดข้อมูลผู้ป่วยตามเกณฑ์ที่อนุมัติ ไม่ควรสมมติว่าข้อมูลส่งออกถูกคัดกรองแล้ว ระบบแยก RBC เกล็ดเลือด และส่วนประกอบอื่นก่อนใช้กฎ

## ข้อบ่งชี้เกล็ดเลือด

กฎใน `prompt_builder/system_prompt.py` และ `platelet_guardrail/models.py` ใช้ร่างนโยบาย Chula ค่า 10,000, 20,000, 50,000 และ 80,000/µL รวมค่าที่เท่ากับเกณฑ์ ส่วนเกณฑ์ 100,000/µL ต้องต่ำกว่าเท่านั้น

| ข้อบ่งชี้ที่มีหลักฐานรองรับ | เกณฑ์จำนวนเกล็ดเลือด |
| --- | --- |
| Lumbar puncture | ≤ 50,000/µL สำหรับอายุรกรรมหรือสูติกรรม, ≤ 80,000/µL สำหรับศัลยกรรมหรือออร์โธปิดิกส์ |
| CVC, thoracocentesis, arthrocentesis หรือถอนฟัน | ≤ 50,000/µL การเจาะหรือตัดชิ้นเนื้อไขกระดูกไม่เข้าเงื่อนไขนี้ |
| ผ่าตัดใหญ่ที่ไม่ใช่ neuraxial ซึ่งวางแผนไว้หรือทำใน 24 ชั่วโมงก่อนหน้า | ≤ 80,000/µL หรือ < 100,000/µL หากเสี่ยงเลือดออกสูง |
| Consumptive thrombocytopenia หรือ DIC ที่ไม่มี active bleeding | ≤ 10,000/µL |
| Chemotherapy หรือ HSCT ที่ไม่มี active bleeding | ≤ 10,000/µL หรือมีแนวโน้มที่คำนวณได้ว่าจะลดถึง ≤ 10,000/µL ใน 24 ชั่วโมง |
| เลือดออกในกะโหลกแบบ acute, acute-on-chronic, เพิ่มขึ้น หรือมีแผนผ่าตัด | < 100,000/µL ช่วง acute นับเจ็ดวันจาก note หรือภาพตรวจที่ยืนยัน |
| เลือดออกในกะโหลกที่คงที่และไม่ผ่าตัด | ≤ 50,000/µL |
| Active bleeding ที่มีนัยสำคัญทางคลินิก | ≤ 50,000/µL |
| Aplastic anaemia ที่กำลังรักษาเพื่อแก้ภาวะเกล็ดเลือดต่ำ | ≤ 10,000/µL หรือคาดการณ์ว่าจะลดถึงระดับนั้นใน 24 ชั่วโมง ระหว่าง ATG หรือมี sepsis ใช้ ≤ 20,000/µL |

ระบบคำนวณแนวโน้มจากผลก่อนสั่งสองครั้งล่าสุดที่ใช้ได้ ค่าเป้าหมายใน standing order ไม่ใช่แนวโน้มของผลตรวจ

กลุ่มที่ต้องระวังเป็นพิเศษรวม dengue ที่ไม่มีเลือดออก, TTP, HIT, ITP, snakebite ที่ไม่มีเลือดออกตามเงื่อนไข และ chronic marrow failure ที่ไม่มีบริบทการรักษาซึ่งเข้าเกณฑ์ จำนวนเกล็ดเลือดต่ำเพียงอย่างเดียวไม่ทำให้ผ่าน ต้องตรวจข้อยกเว้นเฉพาะโรคตามนโยบายฉบับเต็ม

ในขั้น LLM รหัสวินิจฉัยเพียงอย่างเดียวใช้ยืนยันข้อบ่งชี้หรือข้อยกเว้นไม่ได้ ยกเว้นกฎ prophylaxis แบบ deterministic ที่ตั้งใจใช้ข้อมูลเชิงโครงสร้าง กฎนี้เปิดโดยค่าเริ่มต้นและอาจให้ผ่านเมื่อผลตรวจยังใหม่ จำนวน ≤ 10,000/µL มีรหัสโลหิตวิทยา เคมีบำบัด หรือปลูกถ่ายที่เข้าเงื่อนไข และไม่มีรหัสข้อยกเว้น บางรหัสต้องมีหลักฐานเคมีบำบัดเพิ่ม

เส้นทาง LLM สำหรับเกล็ดเลือดยังปิดโดยค่าเริ่มต้น จึงอาจทำให้ audit ไม่ครบ ดู [ระบบนี้คืออะไร](/blood_audit/th/clinical/what-this-is/) การตรวจว่าเอกสารตรงกับโค้ดไม่ได้ยืนยันความถูกต้องของนโยบาย โมเดล หรือระบบที่ติดตั้งจริง
