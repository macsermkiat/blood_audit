`bba ingest` ตรวจชุด CSV จาก HOSxP และปรับรูปแบบข้อมูล เมื่อผ่านครบจะบันทึก completion marker ใช้ `bba audit` เมื่อต้องการจัดประเภทคำสั่งเลือดและบันทึก audit rows

```sh
export BBA_DATA_DIR=/srv/bba/data
uv run bba ingest /srv/bba/export/BDVST.csv --schema-version v1
```

ไฟล์มาตรฐานทั้งหมดต้องอยู่ในไดเรกทอรีเดียวกัน ผู้ส่งออกต้องกรองกลุ่มผู้ใหญ่ตามขอบเขตที่อนุมัติ เพราะชุดข้อมูลไม่มีคอลัมน์อายุ

<h2 id="expected-tables">ไฟล์ที่ต้องมี</h2>

| CSV | การใช้งาน |
| --- | --- |
| `BDVST.csv` | หัวคำสั่ง รหัสผู้ป่วยและการนอนโรงพยาบาล ชนิดเลือด เวลาขอ และแพทย์ผู้สั่ง `DCTREQ` |
| `BDVSTDT.csv` | รายละเอียดผลิตภัณฑ์และการใช้ที่ระบุด้วย `USETYPE` |
| `BDVSTTRANS.csv` | สถานะรายยูนิต เช่น คืน ใช้แล้ว และเข้ากันไม่ได้ |
| `BDTYPE.csv` | ตารางอ้างอิงผลิตภัณฑ์เลือด |
| `BDVSTST.csv` | ตารางอ้างอิงสถานะ |
| `Diagnosis.csv` | รหัสวินิจฉัยสำหรับกลุ่มโรคและเกณฑ์คัดออก |
| `Lab.csv` | Hb จำนวนเกล็ดเลือด และผลตรวจอื่น |
| `Med.csv` | หลักฐานยา |
| `IPDADMPROGRESS.csv` | บันทึกความก้าวหน้าที่เก็บในเครื่องจนผ่านการลบข้อมูลและตรวจสิทธิ์ส่ง |
| `IPDNRFOCUSDT.csv` | บันทึกพยาบาลที่ต้องผ่านข้อกำหนดเดียวกัน |
| `IPTSUMOPRT.csv` | เหตุการณ์ผ่าตัดและเวลา |
| `INCPT_OPRTACT.csv` | ค่าหัตถการที่ join ด้วย `Income` ไว้แล้ว |
| `ICD9CM.csv` | พจนานุกรมหัตถการและการจัดกลุ่ม OR |

schema และกฎปรับรูปแบบอยู่ใน `src/bba/ingest/` ระบบแปลงชื่อคอลัมน์ตาม mapping ตัดชื่อซ้ำ และเลือกเฉพาะคอลัมน์ที่รู้จัก คอลัมน์ส่วนเกินจะถูกตัดออกพร้อมบันทึกไว้ หากขาดคอลัมน์หรือไฟล์ที่จำเป็น การตรวจจะไม่ผ่าน

`DCT.csv` เป็นข้อมูลเพิ่มสำหรับระบุแพทย์ในรายงานและหน้าทบทวน ไม่ใช่หนึ่งใน 13 ไฟล์มาตรฐาน

## ผลจาก ingest

คำสั่งใช้ `$BBA_DATA_DIR/ingest/v1/` เป็น output root และสร้าง `_run_<run_id>.complete` เมื่อผ่านการตรวจและปรับรูปแบบครบ ingest แบบแยกไม่ได้เขียนตาราง Parquet ที่ปรับรูปแบบแล้วหรือผลจัดประเภท `AuditRow`

ชุดข้อมูล schema และรุ่นโค้ดเดิมใช้ ingest identity ที่เสร็จแล้วได้ หากไม่มี completion marker การรันครั้งถัดไปจะตรวจใหม่

audit มี run identity snapshot และการบันทึกผลของตนเอง การมี ingest marker จึงไม่ได้แปลว่าตรวจคำสั่งเลือดแล้ว ดู [ตรวจข้อมูลครั้งแรก](/blood_audit/th/operators/first-audit-run/)

## ปกป้องข้อมูลส่งออก

เก็บไฟล์ส่งออกและผลที่ได้ไว้นอก repository การเข้ารหัส identifier ไม่ได้ยืนยันว่าข้อมูลเผยแพร่ได้ ใช้ข้อมูลสังเคราะห์ เช่น `PHI_xxx_001` ในเอกสาร ภาพหน้าจอ และ issue
