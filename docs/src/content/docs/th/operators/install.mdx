ติดตั้ง Python 3.13 ขึ้นไปและ uv แล้วใช้ lockfile เพื่อติดตั้ง dependency ของ repository

```sh
git clone https://github.com/macsermkiat/blood_audit.git
cd blood_audit
uv sync --frozen
uv run bba --help
```

หน้าช่วยเหลือแสดงหกคำสั่ง ได้แก่ `audit`, `evaluate`, `ingest`, `report`, `sentinel` และ `serve-dashboard` ใช้ `--help` ต่อท้ายแต่ละคำสั่งเพื่อดูอาร์กิวเมนต์

โหมด local ไม่ต้องเชื่อม Postgres และไม่ต้องใช้ API key ทำต่อที่ [ตรวจข้อมูลครั้งแรก](/blood_audit/th/operators/first-audit-run/)

## ติดตั้ง dependency สำหรับ live

สำหรับระบบที่ได้รับอนุมัติให้ส่งข้อมูลไปยังโมเดลจริง ให้ติดตั้ง dependency เพิ่ม

```sh
uv sync --frozen --extra live
```

ใช้ `uv run --extra live bba ...` เมื่อรันโหมดนี้ เพื่อให้ uv เก็บ dependency ของผู้ให้บริการไว้ ตั้งค่า [การทบทวนด้วยโมเดล](/blood_audit/th/operators/env-vars/#model-review) ให้ครบก่อนใช้ข้อมูลโรงพยาบาล

## เตรียมฐานข้อมูลสำหรับใช้งานจริง

ใช้ source checkout เมื่อติดตั้ง model checkpoint หรือบริการหน้าทบทวน โครงการ migration ของ Alembic อยู่ที่ root และไม่ได้รวมใน standalone wheel ต้องใช้ migration ที่ตรงกับรุ่นแอปและเตรียมสิทธิ์ฐานข้อมูลก่อนเริ่มบริการ

หน้าทบทวนตรวจ migration และสิทธิ์ของบัญชีฐานข้อมูลตอนเริ่ม ต้องใช้บัญชี reviewer ที่ไม่มีสิทธิ์เกินจำเป็น มี HTTPS reverse proxy และมี identity adapter ที่ออก session พร้อมลายมือชื่อ ดู [เปิดหน้าทบทวนที่ยืนยันตัวตนแล้ว](/blood_audit/th/operators/integration-seams/#serve-authenticated-review)

Docker ใช้สำหรับการทดสอบ Postgres ผ่าน container ไม่ใช่ข้อกำหนดของการตรวจแบบ local ดู [การทดสอบ](/blood_audit/th/developers/testing/)
