`bba.quote_grounder.verify_citation` ตรวจข้อความอ้างอิงจากโมเดลกับหลักฐานที่ปกปิดแล้ว โดยปฏิเสธ quote ว่างก่อน จากนั้นตรวจตามลำดับจนพบข้อแรกที่ไม่ผ่าน citation ที่ผ่านต้องผ่านการตรวจที่เกี่ยวข้องทุกข้อ

## ผลการตรวจ

verifier คืนเหตุผลแรกที่ไม่ผ่าน source ID ที่ไม่มีหรือซ้ำให้ `CITED_ID_NOT_FOUND` การเทียบข้อความใช้ Unicode NFC และขอบเขตคำ การนับความซ้ำใช้ขอบเขตคำแบบเดียวกัน

การตรวจตัวเลขเปรียบเทียบชุด analyte, value และ unit ที่รองรับ หากโมเดลให้ `lab_tuple` ต้องตรงกับค่าที่แยกจาก quote เอง การตรวจนี้ไม่ได้ตรวจตัวเลขทุกชนิดหรือพิสูจน์ว่าข้อสรุปทางคลินิกถูกต้อง

pipeline ตรวจแต่ละครั้งกับหลักฐานที่ปกปิดแล้วของแถวนั้น และเลือกครั้งล่าสุดที่ผ่าน หากไม่มีครั้งใดผ่าน จะบันทึก `final_classification = NEEDS_REVIEW` พร้อม `review_reason = "hallucination_suspect"` เหตุผลนี้ไม่ใช่ค่าการจำแนก ดู [Audit store](/blood_audit/th/developers/audit-store/)

การกู้คืนใช้ verifier จริงตัวเดียวกัน คำตอบใน cache ไม่ข้าม grounding และคำขอที่เปลี่ยนไม่ใช้คำตอบเก่าต่อได้เพียงเพราะ audit ID เหมือนเดิม

## การตรวจ NLI เพิ่มเติม

`verify_citation(..., nli_gate=None)` ไม่เรียก NLI ผู้เรียกสามารถส่ง `NLIEntailmentGate` เพื่อตรวจ entailment เพิ่ม แอปพลิเคชันปกติไม่ได้ส่ง gate นี้

gate รับ source ที่ normalize แล้วเป็น premise และ quote ที่ normalize แล้วเป็น hypothesis จึงไม่ได้ตรวจทุกประโยคใน reasoning summary ด้วยตัวมันเอง grounding ยืนยันที่มาของข้อความอ้างอิง ส่วนการตรวจทางคลินิกและการพิจารณาของผู้ทบทวนยังจำเป็น

## ทดสอบขอบเขต

ใช้ verifier จริงกับตัวอย่างสังเคราะห์ที่จงใจท้าทายการตรวจ ครอบคลุม ID ที่ไม่มี, source ID ซ้ำ, quote สั้น, ขอบเขตคำที่เลื่อน, ข้อความซ้ำ และ lab tuple ที่ขัดกัน ค่าปกติคือ `MIN_QUOTE_LENGTH = 25` พารามิเตอร์ `min_length` รองรับการทดลองประเมิน ไม่ใช่เหตุผลให้ลดข้อกำหนดของแอปพลิเคชัน

ลำดับตรวจอยู่ใน `src/bba/quote_grounder/verifier.py` และฟังก์ชันแต่ละข้ออยู่ใน `src/bba/quote_grounder/layers.py`
